# CTF

Apuntes de CTFs (Capture The Flag) jugados o resueltos como práctica.

- No publicar flags/respuestas literales de retos activos o de pago.
- No pegar screenshots sin revisar antes.

## ¿Qué es un CTF?

Un CTF (Capture The Flag) es una competencia o ejercicio de ciberseguridad donde se
resuelven retos técnicos (explotación, criptografía, forense, reversing, web,
esteganografía, etc.) para encontrar una "flag": un string oculto que demuestra que
el reto fue resuelto. Pueden ser individuales o en equipo, con tiempo limitado
(competencias tipo Jeopardy o Attack-Defense) o de práctica libre (retos siempre
disponibles, como picoCTF o los wargames de OverTheWire).

## ¿Para qué sirven?

- Practicar habilidades técnicas de forma legal y en un entorno controlado, sin
  necesidad de autorización sobre sistemas reales.
- Aprender conceptos nuevos (una categoría de CTF suele mapear a un área: pwn/binary
  exploitation, web, crypto, forensics, reversing, OSINT, etc.).
- Prepararse para certificaciones o entrevistas técnicas de seguridad ofensiva.
- Practicar bajo presión de tiempo y resolución de problemas con información
  incompleta.

## Organización

Una carpeta o archivo por CTF/plataforma, por ejemplo:

```
ctf/
  README.md
  _template.md
  picoctf/
  overthewire/
```

Cada nota debería documentar la metodología y el razonamiento (qué se probó, por qué,
qué vulnerabilidad o técnica se usó), no el valor final de la flag.
