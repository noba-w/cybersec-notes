# Herramientas

Notas de herramientas y protocolos de uso general (qué son, para qué sirven, comandos
básicos), sin atarlas a una plataforma o sala concreta. Los write-ups de salas/máquinas
que las usan van en `tryhackme/`, `hackthebox/` o `ctf/`, y pueden enlazar acá en vez
de repetir la teoría.

Un archivo por herramienta/protocolo, por ejemplo:

```
herramientas/
  README.md
  nmap.md
  ftp.md
  dirbuster.md
  comandos-basicos.md
```
